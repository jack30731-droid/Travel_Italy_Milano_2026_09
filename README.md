# 🇮🇹 2026.09-Portofino: Italian Riviera & Renaissance Travel Booklet
> **《2026 義大利經典與蔚藍海岸秘境：14 天自由行大眾分享全攻略》**
> An interactive, offline-ready web guide & travel booklet for a 14-day trip across the Italian Riviera, Tuscany, and the Swiss Alps.

---

## 🌟 專案簡介 (Project Overview)

本專案為 **2026 年 9 月義大利經典與蔚藍海岸秘境 14 天 11 夜自由行** 的互動式 Web 應用程式與旅行導覽手冊公開分享版。

全卷行程深入探索利古里亞海岸（Camogli, San Fruttuoso, Santa Margherita Ligure, Portofino）、托斯卡尼文藝復興心臟（Florence, Siena, Pisa）、瑞士阿爾卑斯伯爾尼納冰川快車（Bernina Express）以及米蘭（Milano）。

---

## 🗺️ 14 天行程探索節點 (City Corridor)

1. **Camogli (卡莫利)** ｜ 利古里亞海濱漁村住宿基地、德拉戈納拉城堡與雷科起司佛卡夏發源地。
2. **San Fruttuoso (聖弗羅托索)** ｜ 國家公園無車秘境，搭乘渡輪探訪千禧本篤會石造修道院。
3. **Santa Margherita Ligure (聖瑪格麗塔-利古雷)** ｜ 優雅海濱長廊、杜拉佐別墅與前往波托菲諾的公車轉乘樞紐。
4. **Portofino (波托菲諾)** ｜ 世界奢華名流港灣，漫步親吻步道、攻頂布朗城堡遠眺無敵海景。
5. **Firenze (佛羅倫斯)** ｜ 文藝復興搖籃，朝聖烏菲茲美術館、百花大教堂與托斯卡尼酒莊。
6. **Milano & Swiss Alps (米蘭與瑞士阿爾卑斯)** ｜ 布雷拉畫廊朝聖，搭乘伯爾尼納快車跨越莫特拉奇冰川。

## 🚆 交通系統結構 (Ligurian Riviera Transit Guide)

本導覽將交通系統分為三大邏輯區段，方便隨時查閱：

- **Part A ｜ 城際與高鐵時刻表 (Intercity & High-Speed Rail)**
  - 涵蓋 Malpensa Express、Intercity (IC 665 / IC 511) 與 Italo 高鐵搭乘指引與購票說明。
- **Part B ｜ 利古里亞海岸渡輪 (Ligurian Ferries)**
  - 包含 *Golfo Paradiso* (Camogli ➔ San Fruttuoso) 與 *Traghetti Portofino* (San Fruttuoso ➔ Santa Margherita Ligure) 船班與碼頭購票指南。
- **Part C ｜ 波托菲諾專屬接駁動線 (Portofino Bus 782 Transit)**
  - **Step 1:** 自 Camogli 搭乘區間車 (Regionale) 1 站至 Santa Margherita Ligure-Portofino 站。
  - **Step 2:** 火車站前圓環轉乘 782 號公車，15–20 分鐘直達波托菲諾終點站。

## 💻 Web App 功能亮點 (Features)

- 📱 **100% 響應式與離線可用 (Offline-Ready Single HTML):** 無須架設後端伺服器，單一 HTML 檔案下載至手機即可離線開啟。
- 🗓️ **14 天每日時間軸切換 (Interactive Day Selector):** 點擊即可即時切換 14 天每日行程詳細動線。
- 📍 **40+ 景點與美食目錄 (Searchable Places Directory):** 支援關鍵字搜尋與城市分類篩選。
- 💶 **歐元即時換算機 (Live Currency Calculator):** 內建 1 EUR ≈ 36.8 TWD 即時預算試算與花費結構分析。
- 🛡️ **大眾公開版脫敏處理 (Public Safety Compliant):** 已去除所有個人 PNR 訂位代號、私人訂單號與個資，適合公開分享與參考。

## 🚀 如何使用與部署 (How to Run / Deploy)

### 1. 本地開啟 (Local Run)
只需將本 Repo 的 `index.html` 下載至您的電腦或手機，直接雙擊在任何瀏覽器 (Chrome, Safari, Edge) 中開啟即可。

### 2. 開啟 GitHub Pages 免費線上預覽 (GitHub Pages Deployment)
1. 前往本 GitHub Repository 的 **Settings** $\rightarrow$ **Pages**。
2. 在 **Branch** 選項中選擇 `main` 分支並選取 `/ (root)` 資料夾。
3. 點擊 **Save**，數分鐘後即可取得專屬公開網址！
